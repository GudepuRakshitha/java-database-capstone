# User Stories - Smart Clinic Management System

### Admin
- As an Admin, I want to add new doctors to the system so that patients can book appointments with them.
- As an Admin, I want to manage patient records to ensure data accuracy.

### Doctor
- As a Doctor, I want to view my daily schedule so that I can prepare for my patients.
- As a Doctor, I want to access patient medical history to provide better care.

### Patient
- As a Patient, I want to search for doctors by name or specialty so that I can find the right care.
- As a Patient, I want to book an appointment online for a specific time slot.
